## LUXURY & PREMIUM ADDENDUM (owner request 2026-10-31: "the whole website should look very luxurious and premium") — BINDING FOR EVERY SECTION
Luxury here = restraint + craft, inside the brand guide (no new colours/fonts). Apply everywhere:
1. SPACE: generous section padding (clamp 96–160px vertical on desktop), wide gutters, max 60–68ch line length for body, one idea per viewport. Never crowd cards; prefer fewer, larger elements.
2. TYPE: Clash Display large and confident (H1 up to ~88px on wide screens, tight -2% tracking), light visual weight via size not boldness; Satoshi body 17–18px / 1.6; JetBrains Mono labels with +12% tracking. Numerals in tabular lining figures. Hairline (1px #D5DDD8 / #2B3932) rules, numbered section markers (01 — Platform) as editorial furniture.
3. SURFACES: layered but quiet — White cards on Soft White with 1px hairline borders + ultra-soft layered shadow (0 1px 0 rgb(11 15 14 / .04), 0 24px 48px -24px rgb(11 15 14 / .14)); Ink blocks with a faint Night-Panel inner panel and 1px Night Line borders; inset 1px white-alpha highlights on dark cards. No heavy drop shadows, no bevels, no glass-blur overuse.
4. IMAGERY: full-bleed, high-quality photography with slow Ken-Burns (scale 1→1.04 over ≥12s, transform only), Ink fade masks, rounded-corner frames (radius 20–28px) with 1px white-alpha inner border; duotone is NOT allowed (keeps true colour). Gold/bronze or any new accent colour is NOT allowed — luxury comes from Ink, whitespace and one precise green.
5. MOTION: slow, weighted easing (cubic-bezier(.16,1,.3,1), 700–1100ms reveals, 80–120ms staggers), magnetic primary buttons (small translate, desktop pointer only), smooth anchor scroll, number count-ups only for true figures, page-load choreography after the preloader (header drops in, hero lines mask-reveal upward line by line). Always reduced-motion safe. Nothing bouncy or playful; no confetti.
6. DETAIL: custom ::selection (Mint), refined focus rings, thin custom scrollbar inside landing, subtle noise-free flat backgrounds, button micro-interactions (arrow slides 4px, underline draws), consistent 8px grid, optical alignment of icons, tabular figures in prices, crisp 1px device bezels, ticket-stub perforations as a recurring motif (limit to 3 places).
7. COPY PRESENTATION: short lines, generous leading, balanced wraps (text-wrap: balance on headings, pretty on paragraphs), no more than 3 lines of body copy per card, eyebrow + heading + one-sentence lede pattern in every section.
8. SELF-CHECK before reporting: would this look at home next to Linear/Stripe/Aesop/Four Seasons marketing sites? If any element looks like a template (generic icon grid, stock gradient, cramped table), redesign it.
